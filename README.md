# تطبيق «رفيق الهاتف» — النسخة الكاملة مع الخادم الخلفي وقاعدة البيانات المشتركة (Node.js + Express + Render PostgreSQL)

تتيح هذه الحزمة تشغيل تطبيق **«رفيق الهاتف»** كخدمة ويب متكاملة (`Full-Stack Web Service`) على منصة **Render** بحيث يتم حفظ الشروحات التي يضيفها المتطوعون داخل قاعدة بيانات مشتركة (`PostgreSQL` أو ملف `JSON` احتياطي تلقائي) لتظهر فوراً لجميع المستخدمين.

## هيكلة الملفات
- `server.js`: خادم Node.js مبني بإطار `Express` يقدم الواجهة الأمامية ويوفر مسارات:
  - `GET /api/health`: لفحص حالة الخادم ونوع قاعدة البيانات المتصلة.
  - `GET /api/guides`: لجلب جميع الشروحات التي أضافها المتطوعون.
  - `POST /api/guides`: لحفظ شرح جديد في قاعدة البيانات المشتركة.
- `package.json`: ملف الحزم البرمجية وأمر التشغيل (`npm start`).
- `render.yaml`: ملف الإعداد التلقائي (Blueprint) الذي ينشئ خادم Node.js وقاعدة بيانات `PostgreSQL` مجانية على Render ويربطهما معاً تلقائياً عبر المتغير `DATABASE_URL`.
- `public/`: مجلد الواجهة التفاعلية الكاملة (`index.html`، `manifest.json`، `sw.js`).
- `data/community_guides.json`: ملف بيانات أولي يعمل كقاعدة بيانات محلية تلقائياً إذا لم يتم ربط `DATABASE_URL`.

## خطوات الرفع على GitHub والربط مع Render
1. ارفع جميع ملفات هذا المجلد إلى مستودعك في **GitHub**.
2. في منصة **Render**:
   - **الطريقة الأسهل (التلقائية بالكامل):** اضغط **New +** ثم اختر **Blueprint** واربط المستودع؛ سيقرأ Render ملف `render.yaml` وينشئ الخادم وقاعدة بيانات PostgreSQL ويربطهما بضغطة واحدة.
   - **الطريقة اليدوية (Web Service):** اضغط **New +** ثم اختر **Web Service**، واجعل `Build Command` هو `npm install` و `Start Command` هو `npm start`.
